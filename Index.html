Help & changelog

Getting started

Use the onboarding flow to choose an industry preset, set your brand, and enter a role-aware workspace. Open Template Builder at any time to change modules, density, themes, and permissions.

Keyboard shortcuts

  • Ctrl / ⌘ + K — command palette
  • / — focus global search
  • Escape — close overlays and dialogs

Changelog

v1.4 — Workspace Generator, vertical starter packs, visual automation builder, demo-data generator, component library, accessibility controls, and handoff documentation.

v1.3 — Presentation mode, industry launchers, and marketplace demo polish.

v1.2 — Branded dialogs, undoable deletes, CSV preview validation, sortable paginated tables, deep links, and backend adapter hooks.

Backend integration

The local data adapter is isolated behind clear functions so a future REST, Supabase, Firebase, or custom API connection can replace browser persistence without rewriting the UI.
